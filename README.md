# Calculator (Web) 🧮💻

> Webes számológép - Iskolai projekt SCSS-sel és vanilla JavaScript-tel

## 🎯 Projekt célja

Ez egy egyszerű, de funkcionális webes számológép, amelyet SCSS-sel és natív JavaScript-tel készítettem iskolai feladatként. A projekt célja az SCSS és a JavaScript alapjainak gyakorlása volt.

## ✨ Funkciók

- ➕ **Alapműveletek** - Összeadás, kivonás, szorzás, osztás
- 🔢 **Tizedesjegyek** - Támogatja a decimális számokat
- 🎨 **SCSS styling** - Modern és tiszta kinézet
- 🖱️ **Interaktív UI** - Gombokkal vagy billentyűzettel használható
- ⚡ **Vanilla JavaScript** - Framework nélküli, tiszta kóda

## 🛠️ Technológiák

- **HTML5** - Struktúra
- **SCSS** - CSS preprocessor a jobb stíluskezeléshez
- **Vanilla JavaScript** - Számológép logika és interaktivitás

## 💭 Fejlesztési folyamat

Ez egy iskolai projekt volt, amelynek célja az SCSS preprocessor és a JavaScript alapjainak gyakorlása. Az SCSS használata lehetővé tette a CSS kód jobb strukturálását és karbantarthatóságát, míg a vanilla JavaScript segített a DOM manipuláció és az eseménykezelés mélyebb megértésében.

## 🎓 Tanulási célok

A projekt során gyakoroltam:
- SCSS preprocessor használata
- Vanilla JavaScript programozás
- DOM manipuláció és event handling
- Számológép logika implementálása
- Felhasználói interfész tervezése

## 🧮 Használat

A számológép támogatja az alapvető matematikai műveleteket:
- Összeadás (+)
- Kivonás (-)
- Szorzás (×)
- Osztás (÷)
- Tizedesjegyek (.)
- Törlés és visszavonás funkciók

## 🚀 Futtatás

A projekt futtatásához csak egy böngésző szükséges:

1. Klónozd a repót: `git clone https://github.com/bencso/web-calculator.git`
2. Nyisd meg az `index.html` fájlt böngészőben
3. Kezdj el számolni! 🧮

**Megjegyzés:** Ha módosítani szeretnéd az SCSS fájlokat, szükséged lesz egy SCSS compiler-re (pl. Sass).
